# 小簡的注音大冒險

瑪利歐風格的橫向卷軸注音教育遊戲。

**線上遊玩：** https://u11317029.github.io/game11233/ （建議使用 Chrome）

## 玩法
- **小試身手**：用 ← → 移動、空白鍵 / ↑ 跳躍，跳過或踩扁小怪物、收集寶石。台階隨機生成，可以一直往前走。
- **注音魔法對決**：走到大怪物面前就會開始挑戰。開啟相機後，用食指在空中寫出正確的注音（☝️ 寫字、🖐️ 張開手掌送出、✊ 握拳擦掉）。答對三題就能打敗大怪物。
- 沒有相機也可以用滑鼠或觸控在框裡寫字。

手勢偵測使用 [MediaPipe Hand Landmarker](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker)，第一次進入挑戰時需要網路下載模型。

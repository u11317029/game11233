# 小簡的注音大冒險

注音教育互動網站：教材展示、分單元學習單、瑪利歐風格的冒險遊戲。

**線上使用：** https://u11317029.github.io/game11233/ （建議使用 Chrome）

## 網站內容

| 頁面 | 檔案 | 說明 |
| --- | --- | --- |
| 🏠 整體入口 | `index.html` | 彩色滾動式選單、跟著捲動的章節列、會說話的小簡與注音泡泡、今日注音、泡泡暖身小遊戲、學習進度與徽章、單元冒險地圖、教師專區 |
| 📚 教材展示 | `materials.html` | 37 個注音分 10 單元；看圖、聽發音、描寫、手勢空中寫；投影模式 |
| 🎧 聽音辨識 | `listen.html?pair=en-eng` | ㄣ／ㄥ、ㄢ／ㄤ、ㄌ／ㄋ、ㄓ／ㄗ、ㄕ／ㄙ、ㄈ／ㄏ：學一學發音差異＋8 題聽音挑戰 |

## 程式結構
- `js/zhuyin-data.js`：單元、符號、例詞、注音、發音提示，以及聽音辨識的易混淆注音對 `ZHUYIN_PAIRS`（要改課程內容只改這裡）
- `js/airwriter.js`：注音辨識、MediaPipe 手勢偵測、寫字板、朗讀（遊戲與教材共用）
- `js/voice.js`：朗讀（老師錄音優先，否則自動挑最自然的語音；導覽列 🗣️ 可換語音、調速度）
- `js/sfx.js`：音效（Web Audio 合成）、背景音樂、聲音開關
- `js/progress.js`：學習紀錄（存在瀏覽器 localStorage，首頁進度與徽章讀這裡）
- `css/site.css`：入口、教材、學習單共用樣式

## 空中寫字手勢
☝️ 只伸出食指：寫字　✊ 握拳：暫停筆畫（移到下一筆）　✌️ 比 YA 停一下：擦掉　🖐️ 張開手掌停一下：送出

手勢偵測使用 [MediaPipe Hand Landmarker](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker)，需要相機與網路（第一次約下載 8MB 模型）。沒有相機也可以用滑鼠或觸控寫。

## 冒險遊戲玩法
- 🗺️ 世界地圖：每一關是地上的小圓圈，點了小簡會走過去進入關卡（←→ 選、Enter 出發）
- 關卡：1 草原小路、2 海邊沙灘、3 蘑菇森林、4 冰雪山谷、5 火山城堡、∞ 無盡冒險（五個場景輪流）；
- 每關終點玩法不同：龍／章魚是「空中寫注音」對決；第 3 關蜜蜂女王會把小簡抓到天上，要「聽聲音、打下身上有正確注音的蜜蜂」（干擾選項包含容易搞混的注音）；過關依受傷次數得 1～3 顆星並解鎖下一關，大怪物對決只考該關單元的注音
- 台階判定寬鬆：腳超出邊緣一點也站得住、差一點點高度會自動踩上去、離開台階後短時間內仍可起跳
- ❤️ 3 顆愛心：被怪物碰到或掉進坑會少一顆，用完從 🚩 存檔點重新出發（不會 Game Over）
- ❓ 問號方塊：從下面頂，會掉出寶石、愛心或 🪄 魔杖
- 🪄 魔杖：20 秒內按 `X`（平板按「魔」）發射魔法，什麼怪物都打得倒
- 🍄 彈簧蘑菇：可以跳到高空獎勵台
- 怪物：小綠怪、注音史萊姆、蝙蝠（可以踩）；刺刺球、生氣方塊（不能踩）；害羞幽靈（只怕魔法）
- 大怪物：龍與墨水章魚，各關終點各一隻；無盡模式約每 100 公尺輪流出現

## 朗讀聲音
- 自動挑最像真人的語音：Edge 的「曉臻（Natural）」等神經語音 > Chrome 的「Google 國語（臺灣）」> 系統內建語音。導覽列 🗣️ 可以自己選、調速度。
- **老師錄音**：在「教材展示」每個符號下方按「🎙️ 錄符號／錄例詞」，錄下老師自己的聲音（存在這台裝置的瀏覽器裡，不會上傳）；之後整個網站念到這個符號或詞都會優先播放老師的錄音。
- 網路上找不到授權清楚、同一位台灣口音配音員錄製的注音音檔（Wikimedia Commons 的 Lingua Libre 只有零散、多人、多為大陸口音的錄音），所以採用上面兩種做法。
